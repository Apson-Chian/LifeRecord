# 餐食多选与聊天图片（2026-10-16）

适用 iOS 和 Android。

- 添加餐食时可从系统相册一次选多张、继续追加照片。Android 手动记录也直接显示照片入口，按剩余容量限制选择，并可逐张移除。
- 常用餐食改为勾选多项后确认；各按保存的 1 份合并名称、热量和五项营养，附上各自份量与备注。重新打开保留勾选，重新确认替换这组选择，不重复累加；独立选择的照片保留。超出照片上限会提示，营养仍完整填入。
- 教练中的常用餐食入口也支持多选名称。
- iOS 聊天图片随消息存入本机 SwiftData 外部存储，删除对话时级联清理；图片消息显示缩略图和用户原文，可点开多图浏览及缩放，重启后仍保留。Android 保留已有聊天图片存储和放大功能，图片消息不再重复显示图片提示文字。
- 新增 iOS 字段为可选值，兼容旧记录。旧版 iOS 未保存的聊天图片无法恢复，历史提示文字继续保留。
- 过去聊天中的附件不会因再次提问而自动发送给 AI；当前附图仍遵循原接口的数量及图片能力配置。聊天附件仅保存在本机。

验证：iOS 模拟器构建成功，16 组 Swift 回归程序全部通过；其中新增跨数据库重开、多图内容完整性、图片文字显示和级联删除验证，以及多餐食营养合并验证。专用 iOS 测试设备验证多项勾选、合计 325 kcal、照片合并、聊天双图缩略图及点击放大，已有应用数据库升级后可正常打开。

Android Debug 构建、48 项 JVM 测试、Lint 通过；3 项 API 35 设备回归通过，覆盖多餐食合并后保存、重新勾选不重复累计、多个聊天附件重启展示与删除清理、手动记录保存。模拟器验证仅使用合成餐食和图片。
