# 网页优化交付记录

2026 年 10 月 13 日已部署到 https://apsonchian.ltd/liferecord/ 。按用户要求，AI 使用记录的范围保持原样。

- 独立设置面板集中管理 API、主题、导出、退出和注销；手机新增底部导航，增加触摸区域和键盘焦点，危险操作独立显示。
- 支持自定义 Chat Completions HTTPS 地址、模型、Bearer / api-key / 自定义认证头、输出 Token 参数、Temperature 开关、JSON 模式与额外 JSON 参数。每个服务商保存不含密钥的本地预设；密钥按地址与认证配置隔离，只存在页面内存。
- 公网地址检查拒绝本机、内网、混合公私 DNS、明文 HTTP、嵌入账号和非 443 端口；连接固定已校验 IP，TLS 验证原域名，不跟随重定向。认证头拒绝注入和修改 Host/传输头。配置检查不调用计费 AI，不能据此证明模型和密钥有效。
- 新增训练的常规录入/编辑：开始/结束时间、自定义部位、动作、次数、重量和时长；保留旧记录和训练组的额外字段。
- 单条删除有明确确认，AI 批量修改包含删除时再次确认；尚未实现回收站。
- 历史餐食、身体和训练列表每页 20 条。网页自动同步使用 GET + ETag，没变化返回 304；不再周期上传全快照。变更后仍读取完整快照，不是逐条增量同步；服务端仍重建快照以计算校验值。
- 请求增加超时、网络错误提示与失败退避；退出清除页面密钥、健康数据、照片与未保存表单。
