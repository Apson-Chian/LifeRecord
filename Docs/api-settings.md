# 接口设置

LifeRecord 支持预设服务和自定义 Chat Completions 兼容接口。接口用于照片识别、智能教练和周报；手动记录不依赖 AI 服务。

## 连接服务

在 App 的「设置 → 接口与模型」或网页的「设置 → API」中配置：

1. 选择预设，或添加一个自定义配置并命名。
2. 填写服务商提供的 HTTPS 接口地址、模型名称和认证方式。
3. 输入该服务商的 API Key。移动端保存并测试连接；网页检查地址与参数后使用，密钥只留在当前页面。

新安装默认使用服务器提供的服务，通过自己的同步账号鉴权，无需填写上游 API Key；也可以切换到自己的接口。服务是否可用取决于账号权限和服务端额度。

## 自定义参数

可调整认证请求头、图片能力与数量、输出长度、Temperature、JSON 响应格式及额外请求参数。地址、模型、图片支持与认证方式应以服务商文档为准；部分兼容服务不支持全部参数。

支持保存、更新、切换和删除多个命名配置。配置名称和额外参数中不要填写密钥，删除配置不会删除健康记录。接口需兼容 Chat Completions；其他原生协议需要兼容网关。

## 密钥与隐私

移动端密钥保存在系统安全存储中，并按接口配置隔离。网页 API Key 仅保存在当前页面内存，刷新后需重新填写。预设服务的上游密钥只保存在服务端，不进入客户端安装包。

启用智能功能时，相关记录、文字和所选照片会发送到当前配置的服务。建议只连接自己信任的服务，并根据需要开启图片和记录写入权限。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| 401 / 403 | 密钥是否完整，认证头是否正确，账号是否有模型访问权限 |
| 402 / 429 | 服务商余额、额度与请求频率 |
| 连接失败或超时 | 网络、HTTPS 地址和服务状态 |
| 能对话但不能识图 | 模型是否支持图片，配置中的图片能力是否开启 |
| 营养识别无法解析 | 是否支持 JSON 响应格式，模型输出是否符合要求 |
